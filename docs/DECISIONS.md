| D5 | 2026-10-24 | Menus and item selection on the keyboard. | "This is a computer after all" — owner. |
| D6 | 2026-10-24 | Game code calls no OS ROM routines; hardware access is isolated in the platform layer. | Planned Atari 5200 port. |
| D7 | 2026-10-24 | 5200 port will explore keypad and second fire button for item selection and modes. | Owner request; keypad mirrors the original's controls. |
| D8 | 2026-10-24 | Add a 1-player mode against a CPU governor. | Owner goal. |
| D9 | 2026-10-24 | Mixed ANTIC modes: mode 2 status bar, multicolour character map, split by DLI. | Owner goal; proven in M0 test. |
| D10 | 2026-10-24 | POKEY sound and music, all newly composed. | Owner goal; D4. |
| D11 | 2026-10-24 | Original overflow bugs (earned gold > 255, crops + boats > 65) are fixed. | No gameplay value in reproducing them. |
| D12 | 2026-10-24 | Map uses ANTIC **mode 5**: one island square = 2 × 1 characters (8 × 16 scan lines), 20 squares × 11 rows under a 2-line mode 2 status bar. Closes Q1. | Matches the original's 160 × 96 tall-pixel grid one-to-one; ~64 square graphics per font instead of ~32; half the screen memory and update work. |
| D13 | 2026-10-24 | Sprites (option A of Q2): double-line P/M; P0/P1 = each player's cursor or steered boat; P2 = both pirates and P3 = both fish, reused down the screen by DLI; missiles as a quad-width fifth player = weather (both storms, reused by DLI); `PRIOR` = `$02`; collisions in software on the grid. Closes Q2 except Q7. | All 8 objects stay hardware sprites with smooth movement; the cursors never share or flicker; weather fits exactly 2 squares wide. |
| D14 | 2026-10-24 | Deviation: when a second pirate or fish school would spawn in a band (top or bottom) already used by the other one of its kind, it spawns in the other band. A second storm waits until the first is at least a row clear of the top. Drift overlaps fall back to 30 Hz flicker. | Lets two objects share one player; the original picks the band 50/50 anyway, so the change is barely visible. |
| D15 | 2026-10-24 | Correction to D13: the weather fifth player is **double** width (`SIZEM` = `$55`), not quad; cursors, boats, pirates and fish are **normal**-width players. A mode 5 square is 8 colour clocks wide. | D13 assumed 16 colour clocks per square; mode 5 pixels are one colour clock. |
| D16 | 2026-10-24 | Map palette (closes Q3): `COLBK` sea blue `$84`, `COLPF0` grass `$C6`, `COLPF1` black `$00` (fort, factory, rebel, crop furrows, outlines), `COLPF2` yellow `$1C` (beach edge, house roof, factory smoke, sail), `COLPF3` white `$0E` via inverse characters (school, hospital; also the weather fifth player). Items differ mainly by shape; hospital is white with a black cross; ownership is shown by island. Art and values from branch `mockup/q3-palette`. | Approved by the owner after viewing the mode 5 mock-up in atari800. |
| D17 | 2026-10-24 | Two-player buying (Q4, provisional): a digit key (0-9) goes to the player holding their joystick fire button. If neither holds fire, it goes to player 1. If both do, the key is ignored. In 1-player games no fire button is needed. Revisit after the first two-player playtest. | One shared keyboard; the Intellivision had a keypad per player. The owner accepted it as worth trying. |
| D18 | 2026-10-24 | Info displays (closes Q4): while held, START shows both total scores, SELECT both populations, OPTION both previous-round scores, in place of the Intellivision side buttons. | Console keys are free and shared by both players, like the info itself. |
| D19 | 2026-10-24 | Pause: **P** toggles pause on the 800 (the 5200 build uses the keypad's PAUSE key). While paused: game tic, round clock, sprites, AI and events stop, sound is muted, the status bar shows PAUSED, and only P (or PAUSE) is read. Space is not used, to avoid accidental pauses in a busy two-player game. | Owner request; the 5200 made pause a standard feature. |
| D20 | 2026-10-24 | Timing (closes Q5): the game logic runs on a 20 Hz tic on both NTSC and PAL. On PAL (50 Hz) a frame accumulator gives a 2-3-2-3 frame pattern, so round length, clock and event rates per second match NTSC in real time. | Owner: timing must be consistent on both standards. |
| D21 | 2026-10-24 | Islands (closes Q6): new island shapes, not Mattel's. Use the custom charset for interesting coastlines (beach edges, rounded corners, diagonal coasts, bays). Each island has at least the original's 29 land squares; target 32-36 buildable squares, equal on both sides, with matching harbour placement, distance to the fish/pirate bands and coastline length. | Owner: "interesting coastlines … and enough space to have fun". |
| D22 | 2026-10-24 | Map cells: rows 0-1 and 9-10 stay open sea (fish and pirate entry bands). Cell kinds: sea, land (buildable), diagonal coast (half land: not buildable, boats can't enter), harbour (one per island, a sea square with a pier on the island's outer side, as in the original), rock (decorative; plays as open sea, see Q8). Bit 7 of a cell marks player 1's squares. Island art is a text picture in `tools/mkfont.py`; coast tiles are chosen automatically from neighbours. | Keeps island data editable as pictures and the rules simple; the outer-side harbour follows the original (`$5924`). |
